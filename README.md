# Tomchi 💧 — aqlli sug'orish yordamchisi

**Умный помощник фермера по поливу** для конкурса [President Tech Award — Incubation Program](https://awards.gov.uz/en/pta/incubation-program).

> Har bir tomchi hisobda — каждая капля на счету.

## Проблема

Узбекистан — одна из самых водозатратных стран мира: свыше 90% воды уходит на орошение,
при арычном поливе теряется до половины. Кризис Аральского моря — прямое следствие.
Большинство фермеров поливают «на глаз», без учёта фазы роста культуры и климата региона.

## Решение

Tomchi рассчитывает **дневную норму полива** для конкретного поля по научной методике
**FAO-56** (эвапотранспирация ET₀ × коэффициент культуры Kc по фазам роста), учитывая:

- регион (14 регионов, климатические нормы ET₀ по месяцам),
- культуру (хлопчатник, озимая пшеница, томаты, виноград, яблоня, бахчевые, картофель),
- площадь поля и способ полива (арычный / дождевание / капельный).

### Возможности

- **Бугун / Сегодня** — норма воды на сегодня (капля-датчик), фаза роста, интервал полива, подкормка
- **Тақвим / Календарь** — сезонный график полива по месяцам, итог за сезон
- **Ташхис / Диагноз** — определитель болезней и вредителей по симптомам с рекомендациями
- **Тежамкорлик / Экономия** — сэкономленная вода (м³) и деньги (сум) против арычного полива

Полностью двуязычный интерфейс: **o'zbekcha (default) / русский**.
Работает офлайн-логикой на клиенте — не требует бэкенда и API-ключей, открывается на любом телефоне.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production-сборка в dist/
```

## Стек

Vite · React 18 · TypeScript · Tailwind CSS 4. Данные и расчётный движок — `src/data/`, `src/engine/`.

## Дорожная карта

- Интеграция прогноза погоды (реальный ET₀ вместо климатических норм)
- Фото-диагностика болезней через vision-модель
- Уведомления о поливе через Telegram-бот
- Кабинет водного хозяйства: агрегированная экономия по районам

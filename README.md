# Tomchi — aqlli sug'orish yordamchisi

**Умный помощник фермера по поливу.** Проект для
[President Tech Award — Incubation Program](https://awards.gov.uz/en/pta/incubation-program).

> Har bir tomchi hisobda — каждая капля на счету.

## Проблема

Свыше 90% воды в Узбекистане уходит на орошение, при арычном поливе теряется до
половины. Большинство фермеров поливают «на глаз», без учёта фазы роста культуры
и погоды. Кризис Аральского моря — прямое следствие.

## Решение

Tomchi отвечает на два вопроса — **сколько воды нужно полю сегодня** и **когда
поливать следующий раз** — и позволяет **запустить полив, не выходя в поле**.

Норма считается по методике **FAO-56**: эвапотранспирация ET₀ × коэффициент
культуры Kc по фазе роста, делённая на КПД способа полива. Запас влаги в
корневом слое отслеживается водным балансом FAO-56 (TAW / RAW / дефицит Dr).
Входные данные — 14 регионов с климатическими нормами ET₀, прогноз Open-Meteo,
культура, площадь, тип почвы и способ полива.

## Экраны

| | |
|---|---|
| **Сегодня** | Норма воды, влажность почвы, фаза роста, интервал, подкормка, здоровье поля со спутника |
| **Полив** | Запуск полива по норме, живой прогресс, остановка, история сеансов |
| **Календарь** | График по месяцам, ближайшие поливы, итог за сезон |
| **Агроном** | Диагностика болезней и вредителей — текстом, голосом или по фотографии |
| **Экономия** | Сэкономленная вода и деньги против арычного полива, карта по регионам |

Ещё: дождь автоматически засчитывается вместо полива; границы поля обводятся
пальцем по спутниковому снимку и площадь считается геодезически; NDVI по
снимкам Sentinel-2; Telegram-бот с напоминаниями; печатный отчёт для хокимията;
целиком два языка — o'zbekcha и русский; PWA, расчёт работает офлайн.

## Удалённый полив

Летом при +40 выходить в поле опасно для здоровья. Фермер открывает приложение,
видит рассчитанную норму и запускает полив с телефона.

Сеанс описан **метками времени, а не тикающим таймером**: прогресс вычисляется
из времени старта и планового окончания при каждом чтении. Поэтому полив
продолжается, когда приложение закрыто или телефон выключен — как у настоящего
контроллера. Сеанс не длиннее 8 часов, второй поверх активного невозможен,
остановка доступна всегда. Завершает сеанс серверный планировщик, он же пишет
в журнал и уведомляет в Telegram.

Сейчас это виртуальное устройство, помеченное в интерфейсе как демо-режим.
Слой драйвера `src/lib/devices.ts` — единственная точка связи с устройством:
при подключении реального контроллера меняется только его реализация.

## Стек

**Клиент** — Vite · React 18 · TypeScript · Tailwind CSS 4 · Leaflet. Расчётное
ядро в `src/engine/` — чистые функции без сети и хранилища, покрыты тестами.

**Сервер** — Netlify Functions: агроном, транскрипция голоса, NDVI, вебхук
Telegram, ежедневная рассылка, планировщик полива. Каждый публичный эндпоинт
ограничен по частоте запросов.

**Данные** — Supabase: анонимная аутентификация и row-level security, владелец
видит только свои строки. Бот работает через service role.

Без облака приложение остаётся полезным: норма, водный баланс, календарь и
экономия считаются на устройстве.

## Дорожная карта

Ближайшее — физический слой поля: контроллер клапана, датчики влажности и
метеостанция на участке, камеры с наблюдением за поливом из приложения,
автоматические правила без участия человека, подписка на управление полем.

Дальше — переход от поля к хозяйству: несколько зон полива на одно поле, роли и
совместный доступ, кабинет водного хозяйства района.

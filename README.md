# Tomchi — aqlli sug'orish yordamchisi

**Умный помощник фермера по поливу** для конкурса [President Tech Award — Incubation Program](https://awards.gov.uz/en/pta/incubation-program).

> Har bir tomchi hisobda — каждая капля на счету.

## Проблема

Узбекистан — одна из самых водозатратных стран мира: свыше 90% воды уходит на орошение,
при арычном поливе теряется до половины. Кризис Аральского моря — прямое следствие.
Большинство фермеров поливают «на глаз», без учёта фазы роста культуры и климата региона.

## Решение

Tomchi отвечает на два вопроса: **сколько воды нужно полю сегодня** и **когда поливать
следующий раз**, — а затем позволяет **запустить полив, не выходя в поле**.

Норма считается по методике **FAO-56**: эвапотранспирация ET₀ × коэффициент культуры Kc
по фазам роста, делённая на КПД способа полива. Запас влаги в корневом слое отслеживается
водным балансом FAO-56 (TAW / RAW / накопление дефицита Dr), а не «на глаз» и не таймером.

Учитываются регион (14 регионов с климатическими нормами ET₀ по месяцам), культура,
площадь, тип почвы и способ полива — арычный, дождевание или капельный.

## Что умеет

| Экран | Что делает |
|---|---|
| **Бугун / Сегодня** | Норма воды на сегодня, влажность почвы, фаза роста, интервал полива, подкормка, здоровье поля со спутника |
| **Суғориш / Полив** | Пульт: запуск полива по рассчитанной норме, живой прогресс, остановка, история сеансов |
| **Тақвим / Календарь** | Сезонный график полива по месяцам, ближайшие поливы, итог за сезон |
| **Агроном** | Диагностика болезней и вредителей: текстом, голосом или **по фотографии** |
| **Тежамкорлик / Экономия** | Сэкономленная вода и деньги против арычного полива, карта экономии по регионам |

Отдельно:

- **Реальная погода.** Прогноз Open-Meteo даёт фактический ET₀ и осадки на неделю вперёд;
  дождь автоматически засчитывается вместо полива.
- **Здоровье поля из космоса.** Индекс NDVI по снимкам Sentinel-2 с динамикой за сезон.
- **Границы поля по спутнику.** Фермер обводит участок пальцем на снимке — площадь
  считается по сферической геодезической формуле, а не вводится по памяти.
- **Telegram-бот.** Напоминания о поливе, ответы по полю, привязка и отвязка из приложения.
- **Отчёт для хокимията.** Печатный PDF: расход воды по датам, экономия, методика.
- **Два языка целиком** — o'zbekcha (по умолчанию) и русский.
- **PWA.** Ставится на телефон, расчёт работает офлайн.

## Удалённый полив

Ключевой сценарий: летом при +40 выходить в поле опасно для здоровья. Фермер открывает
приложение, видит рассчитанную норму и запускает полив с телефона.

Сеанс полива описан **метками времени, а не тикающим таймером**: прогресс вычисляется из
времени старта и планового окончания при каждом чтении. Поэтому полив продолжается, когда
приложение закрыто, телефон выключен или фермер зашёл с другого устройства — ровно так же
ведёт себя настоящий контроллер. Завершает сеанс серверный планировщик каждые 5 минут, он
же пишет запись в журнал и шлёт уведомление в Telegram.

Ограничения безопасности: сеанс не длиннее 8 часов, второй сеанс поверх активного
невозможен, остановка доступна всегда, перед запуском — подтверждение с объёмом и временем.

**Сейчас управление работает через виртуальное устройство** — приложение честно помечает
его как демо-режим и показывает список настоящего железа с пометкой «скоро». Слой драйвера
(`src/lib/devices.ts`) — единственная точка, через которую интерфейс общается с
устройством: при подключении реального контроллера меняется только его реализация.

## Стек

**Клиент.** Vite 6 · React 18 · TypeScript · Tailwind CSS 4 · Leaflet. Расчётное ядро —
чистые функции без сети и хранилища в `src/engine/`, данные — в `src/data/`.

**Сервер.** Netlify Functions: чат агронома, диагностика по фото, транскрипция голоса,
NDVI, вебхук Telegram, ежедневная рассылка, планировщик завершения полива. Общий модуль
ограничения частоты запросов на каждый публичный эндпоинт.

**Данные.** Supabase: анонимная аутентификация и row-level security — владелец видит
только свои строки; бот работает через service role. Схема в `supabase/migrations/`.

Приложение остаётся полезным без облака: норма полива, водный баланс, календарь и экономия
считаются на устройстве. Облако нужно для того, что физически требует сервера, — удалённого
полива, бота и синхронизации между устройствами.

## Дорожная карта

Ближайшее — физический слой поля:

- контроллер клапана, датчики влажности и метеостанция на участке;
- камеры на поле и наблюдение за поливом из приложения;
- автоматические правила полива без участия человека;
- подписка на управление полем.

Дальше — переход от отдельного поля к хозяйству: несколько зон полива на одно поле,
роли и совместный доступ, кабинет водного хозяйства района.
